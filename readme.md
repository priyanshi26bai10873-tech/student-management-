# Student Management System

A simple and user-friendly **Student Management System developed using Python** to manage student records efficiently. The project demonstrates basic programming concepts such as functions, loops, conditional statements, lists/dictionaries, input validation, and CRUD operations.

## 📌 Project Overview

Managing student records manually can be time-consuming and may lead to errors. This project provides a simple computerized solution for performing common student record management operations.

The system allows users to:

* Add new student records
* View existing student records
* Search for a student
* Update student information
* Delete student records
* Exit the application safely

## ✨ Features

### 1. Add Student

Allows the user to enter student details and create a new student record.

### 2. View Students

Displays the available student records in an organized format.

### 3. Search Student

Allows users to find a particular student using a suitable student identifier.

### 4. Update Student

Allows existing student information to be modified.

### 5. Delete Student

Allows an existing student record to be removed.

### 6. Input Validation

Handles invalid or unexpected user inputs wherever required.

The main objectives of this project are:
