# Student Management System

## Project Statement

The **Student Management System** is a Python-based console application developed to manage student information in a simple, organized, and efficient manner. The system provides a menu-driven interface that allows users to perform different operations on student records.

The main purpose of this project is to reduce the effort required to maintain student information manually. It allows users to add, view, search, update, and delete student records whenever required.

## Problem Statement

Managing student records manually can be time-consuming and may lead to errors. Searching for a particular student, updating information, and maintaining records becomes difficult as the number of students increases.

The Student Management System provides a computerized solution that organizes student information and makes common record-management operations easier.

## Objectives

* To maintain student records digitally.
* To add new student information.
* To view existing student records.
* To search for a particular student.
* To update student information.
* To delete unwanted or incorrect records.
* To reduce manual record-keeping.
* To minimize errors in maintaining student information.
* To demonstrate practical Python programming concepts.

## Main Features

1. **Add Student** – Adds a new student record to the system.
2. **View Students** – Displays the available student records.
3. **Search Student** – Finds a particular student from the stored records.
4. **Update Student** – Modifies existing student information.
5. **Delete Student** – Removes a selected student record.
6. **Data Storage** – Stores student information for future use.
7. **Input Validation** – Helps handle incorrect or invalid inputs.
8. **Menu-Driven Interface** – Provides different operations through a simple menu.

## Technologies Used

* **Programming Language:** Python
* **Data Storage:** JSON / File Handling
* **Interface:** Console-based
* **Development Environment:** VS Code / Python IDE
